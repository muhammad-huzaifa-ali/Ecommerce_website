# shope ease

End-to-end e-commerce solution to sell, manage, and deliver products online.

## Features

- **Product Catalog:** Organize products by category, view details, and manage inventory.
- **Order Management:** Track, process, and view customer orders with detailed status.
- **Admin Dashboard:** Easily manage products, categories, and users from a centralized panel.
- **Customer Panel:** View and manage registered users.
- **Shopping Experiences:** Curated selections for gaming setups, work-from-home, smart living, and entertainment.
- **Secure Authentication:** Admin and user login/logout, session handling.
- **Responsive Design:** Modern, user-friendly interface ready for all devices.

## Getting Started

This project is built using ASP.NET MVC (C#), HTML, and CSS.

1. Clone this repo.
2. Configure your database connection in `appsettings.json`.
3. Restore NuGet packages.
4. Run with Visual Studio or `dotnet run`.

## Project Structure

- `Controllers/`: Business logic for admin/user, product/order/category management.
- `Models/`: Data models for products, categories, orders, users.
- `Views/`: Razor pages for user/admin experiences.
- `docs/`: Documentation.
