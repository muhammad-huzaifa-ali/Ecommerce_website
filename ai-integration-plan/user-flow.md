# User Flow Comparison

## 🟢 Before (Classic)

```mermaid
flowchart TD
    U1[Landing Page] --> U2[Manual Search/Browse]
    U2 --> U3[Select Product]
    U3 --> U4[Add to Cart]
    U4 --> U5[Checkout (fill info)]
    U5 --> U6[Order Complete]
```

## 🔵 After (Agentic/AI-Driven)

```mermaid
flowchart TD
    UA[User] --> V1[Voice/Chat Intent]
    V1 --> V2[AI Agent: Interprets/User Need]
    V2 --> V3[AI Agent: Finds/Recommends Product]
    V3 --> V4[AI Agent: Adds to Cart]
    V4 --> V5[Checkout (one tap/voice confirm)]
    V5 --> UB[Order Complete]
```

---

## Notes

- User speaks/inputs intent, all steps till order are automated or guided.
- Multi-step manual form-filling and filtering goes away—AI does the heavy lifting.
