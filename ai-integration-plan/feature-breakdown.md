# Feature Breakdown

## Current Features

- Product & Category Management (Admin)
- Browsing, Filtering, Shopping Cart
- Order Management (Admin & User)
- Curated product bundles (Experiences)
- Mobile-friendly, Responsive web UI

## Future/Planned Features

- Voice and chat-based product search & recommendation
- Agent-completed checkout
- Multi-language support
- Real-time price/spec comparison
- Sentiment-adaptive shopping/advice
- Agentic user journey (goal-based, not click-based)
