# Features & Workflows

## Product Catalog

- Browse products by category.
- Detailed product information.
- Product image gallery.

## Order Management

- Admin: Fetch, view, delete, and clear orders.
- User: Buy now, confirm orders, thank you page.

## Admin Panel

- Manage products (add, edit, delete).
- Manage categories.
- View customers.
- Secure login/logout.
- Personalized profile.

## Customer Experience

- Sign in/sign out.
- Explore curated product sets (Gaming, Work From Home, Smart Living, Entertainment).
- Add/remove from cart.
- Order history.

## UI Design

- Responsive HTML & CSS.
- Stylish dashboard, cards, and tables.
- Custom icons and gradients.

For detailed workflows, see code in `/Controllers` and `/Views` directories.
